# Excelショートカット検索

Excel のショートカットを、やりたいことの言葉で探せる辞典のような Web ツールです。

公開URL：https://novalis-lab.github.io/excel-shortcuts/

## できること

- 検索：「合計」「行 挿入」「太字」など、やりたいことの言葉で探せる（入力するたびに絞り込み。ひらがな・カタカナ・全角半角の違いはそろえて探す。言葉はスペースで区切ると「両方を含むもの」になる）
- Windows／Mac の切り替え：押すと全部のキー表示が切り替わる。選んだ方はこの端末のブラウザに保存
- 分類：基本・入力・編集・選択・移動・書式・行・列・シート・ブック・数式・データ・表
- 「まずはこの10個」：よく使うものを一番上に表示
- お気に入り：☆ を押すと登録。「★ お気に入り」ボタンで登録したものだけを表示（この端末のブラウザの中だけに保存。どこにも送信しない）
- 日本語キーボードで押し方が変わりやすいものには、メモを表示

## ファイルの役割

| ファイル | 役割 | さわる頻度 |
|---|---|---|
| `shortcuts.js` | ショートカットのデータ（やりたいこと・キー・補足・分類） | **追加・修正のたび** |
| `index.html` | 画面・色・検索などのしくみ | ほぼさわらない |

## ショートカットを追加・修正する方法

1. `shortcuts.js` を開く
2. 書き方の説明（ファイルの一番上）を見ながら、`{` から `},` までの1セットをコピーして、`SHORTCUTS = [` の中の好きな場所に貼り付ける
3. `id`（ほかと重ならない半角英字）・`title`・`words`・`win`・`mac` を書きかえる
4. 「まずはこの10個」に入れたいときは `top: true,` を付ける（10個に保つため、ほかの1つから外す）
5. `index.html` の `shortcuts.js?v=…` の数字を新しくすると、見る人のブラウザにも確実に反映される

## 正確さについて

- マイクロソフト公式「Excel のキーボード ショートカット」の Windows 版・Mac 版（日本語版と英語版）と照らし合わせ、確認できたものだけを載せています（2026-11-16）
- 片方の OS の公式一覧にしか載っていないものは、その OS を選んだときだけ表示します（もう一方を選んでいるときは「〇件あります」と案内）
- 公式ページ自体に誤記と思われる箇所（Mac 版の「前のシートへ移動」が Ctrl + Page Down になっている）は、確実な Option + ← だけを載せています
- 「日本語キーボードのメモ」は公式ページではなく、一般的な押し方の目安です

## 広告を入れるとき

`index.html` の `<aside class="ad-slot">` の中に広告のコードを貼り、「広告スペース」の文字を消してください。
